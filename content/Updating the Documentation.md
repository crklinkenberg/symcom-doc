The documentation is written in ".md" files and is being maintained in git repertory https://github.com/crklinkenberg/symcom-doc.

Anyone who collaborates to this git repo can have access to edit or add new documentation files.
It is hosted as a website using GitHub Pages and deployed using Quartz.

Once, collaborators push codes to this repo, the changes are automatically reflected on the documentation site. 

The Documentation Link: https://crklinkenberg.github.io/symcom-doc/Symcom-Developer-Home

#### Important Note For Quartz
All notes should be made available inside `content` directory. Any images used should be inside `content/assets/images` directory and should be linked into it using text editor like Obsidian etc.
