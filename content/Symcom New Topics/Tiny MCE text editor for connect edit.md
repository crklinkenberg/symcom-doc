For Connect Edit connection, a special tiny MCE editor has been defined.
This editor is fully dynamic, it is generated when CE button is clicked.
Instead of normal  bold, italics buttons, this editor has been defined button as per grades.

These grade icons or grade buttons are generated dynamically when CE button is clicked. The grade buttons are on basis of the grade setting of the particular symptoms.

For example: If CE button is clicked for a comparative symptom during comparison and this symptom belongs to a source 1880. if for source 1880, only two grades numbers are assigned from the grade setting page, then that two grade numbers will be shown as icons in the CE text editor.

The plugin files are  located in `symcom-core-app/plugins/tinymce`.
The file related is `tinymce.min.js`.

This special text editor is generated by `generateDynamicTinyMceEditor()` JavaScript function which is called from `connect-edit.js` script.

The CSS associated with the editor are defined under `symcom-core-app/plugins/tinymce/css/text.css`.

Basic Workflow:
1. The CE button is associated with HTML class `symptom-connect-edit-btn`. When clicked it is handled by on click event. The script related is `connect-edit.js`.
2.  Inside this script the call for CE modal with the text editor is initiated by `ceModalDisplayFn()` function.
3. For both normal CE or swap CE cases, this `generateDynamicGradeIconsAndTags()` is called which fetches the grade settings of the source associated with the symptom and generates the data needed to generate grade icons and tags in the text editor.
4. Upon successful execution of `generateDynamicGradeIconsAndTags()` function, the grade settings is stored in an input html element with id `dynamic_grade_settings` in the `comparison/index.php` page and a call to `generateDynamicGradeIconsAndTags()` is performed.
5. This function `generateDynamicTinyMceEditor()` which is defined in `comparison-page-functions.js` generates the dynamic text editor using the `tinyMCE`plugin and also has ability to convert the symptom text as it has been defined with `processHtmlContentForDifferentGrades()` function for each grade icon.
6. The functionality of `processHtmlContentForDifferentGrades()` function can be found in the topic of CE connection and disconnection.
